# Conformal Prediction Intervals for Single-Cell Perturbation Effects

When can a single-cell perturbation prediction be trusted? This repository
implements split-conformal prediction intervals for gene-level perturbation
effects (log-fold changes) with robust variance shrinkage and group-conditional
calibration, and evaluates them on sci-Plex3 and Norman single-cell screens.

## Key results

- Synthetic validation reaches nominal 95% coverage (0.947, 5 seeds).
- In-distribution calibration on sci-Plex3 restores coverage to 0.951 ± 0.003.
- Unseen drugs under-cover with the mean-shift predictor (0.866 ± 0.002);
  fixed-width and bootstrap-SE normal intervals under-cover much more.
- DEG prioritization: flagged top-50 precision improves from 0.657 to 0.670
  (5 seeds) while flagging only 9.6% of genes.
- A fine-tuned scGPT base predictor restores unseen-perturbation coverage to
  0.948 ± 0.022 on the same held-out Norman perturbations (delta: 0.910),
  showing that out-of-distribution under-coverage reflects base-predictor
  generalization rather than the conformal procedure.

## Installation

The main pipeline requires a Python environment with:

```bash
pip install -r code/requirements.txt
```

The scGPT comparison additionally requires `scgpt`, `cell-gears`,
`torch_geometric`, and the official scGPT `whole-human` checkpoint
(`best_model.pt`, `vocab.json`, `args.json`) placed under
`externals/scgpt_weights/`. See `code/scgpt_*.py` for details.

## Data

Processed data are not committed because of their size. Download:

- sci-Plex3 (`hvg.h5ad`): from the source reported in the manuscript's data
  availability statement, then place at `data/sciplex3/hvg.h5ad`.
- Norman (`norman_hvg1000.h5ad`): generated by `code/prep_norman.py` from
  GEO accession GSE133344, then placed at `data/norman/`.

> Note: the scripts currently use the absolute paths of the original analysis
> machine (`/mnt/d/guo/CW1OT/...`). Adjust the path constants at the top of
> each script for your environment.

## Reproduce

```bash
# main UQ experiments (WSL/Linux, conda env recommended)
python code/run_uq_supplement.py        # multi-seed S3/S4 + baselines
python code/run_uq_s5.py                # Norman replication
python code/make_figures.py             # regenerate all figures

# scGPT base predictor (requires GPU + scGPT weights)
python code/scgpt_build_norman_union.py
python code/scgpt_finetune_norman.py
python code/run_uq_scgpt_s5.py
```

Individual experiment scripts (`run_uq_s1.py`, `run_uq_s2.py`, `run_uq_s3.py`,
etc.) reproduce the corresponding results sections.
